# AX Payroll

Payroll and HR for Arabic, English and Kurdish, running fully offline on your own PC.

## Download

**[Download AXPayroll-win-Setup.exe](https://github.com/AMXNexus/ax-payroll-releases/releases/latest/download/AXPayroll-win-Setup.exe)** (Windows 10/11, 64-bit)

All versions are listed under [Releases](https://github.com/AMXNexus/ax-payroll-releases/releases) on the right side of this page.

Windows may show "unknown publisher" the first time: choose **More info**, then **Run anyway**.
Once installed, the app checks for new versions when it opens and updates itself after taking a backup. Your data is stored separately and is never touched by updates.
